## 🚀 Start Sharing (Daily Use)

3. Note Connection ID (e.g., `abc123`)

### On Phone:
1. Open ScreenShare Pro app
2. Enter Connection ID
3. Tap "🔗 Connect"
4. Tap "👁️ Viewing"
5. **Done! Enjoy unlimited hours free!** 🎉

## ⚠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't connect | Check both on same WiFi |
| Black screen | Click "Select" then "Start Sharing" |
| Permission error | System Prefs > Security > Screen Recording |
| Phone won't install | Enable USB debugging in Developer Options |

### "Cannot connect":

- Verify server is running (it is! ✅)
- Check IP is correct: `10.210.148.79`

### "Connection ID not found":
- Get latest ID from desktop app window
- Must be exact match (case-sensitive)

### "Black screen":
- Desktop app must have screen selected
- Check Screen Recording permission

### "Page won't load":
- Make sure server is running
- Try: `http://10.210.148.79:3000/api/status`
- Should show server info

# 🚀 START FROM SCRATCH - SIMPLE COMMANDS

Copy and paste these commands to start everything.

---

## Terminal 1: Start Server

```bash
cd "/Users/jitishkumar/Desktop/screen share3/server" && node index.js
```

**Keep this terminal open!** You should see:
```
🚀 ScreenShare Pro Server
📡 Server running on port 3000
```

---

## Terminal 2: Start Desktop App

**Open a NEW terminal window**, then run:

```bash
cd "/Users/jitishkumar/Desktop/screen share3/desktop-app" && npm start
```

**LOOK FOR THIS OUTPUT** (you'll need to copy these):
```
============================================================
📱 MOBILE ACCESS INFO (Copy these)
============================================================
🔗 Mobile Link: http://10.50.31.163:3000
🆔 Connection ID: k6a8fxn0OiruxAY8AAAA
============================================================
```

---

## On Your Phone:

1. **Copy the Mobile Link** from Terminal 2 (example: `http://10.50.31.163:3000`)
2. Open Chrome browser on your phone
3. Paste the link and open it
4. **Copy the Connection ID** from Terminal 2 (example: `k6a8fxn0OiruxAY8AAAA`)
5. Enter it on the phone screen
6. Tap "Connect"

---

## In Desktop App Window:

1. You'll see screen/window options
2. Click on the screen you want to share
3. Click "Select" button
4. Click "Start Sharing" button
5. Your Mac screen appears on your phone! 🎉

---

## To Stop Everything:

Press `Ctrl+C` in both Terminal 1 and Terminal 2.

---

## Next Time You Want to Start:

Just run the same 2 commands again:

**Terminal 1:**
```bash
cd "/Users/jitishkumar/Desktop/screen share3/server" && node index.js
```

**Terminal 2:**
```bash
cd "/Users/jitishkumar/Desktop/screen share3/desktop-app" && npm start
```

**Always look at Terminal 2 for the new Mobile Link and Connection ID!**

---

## If IP Address Changes:

When you disconnect/reconnect your phone's hotspot, the IP changes. Just:
1. Stop both terminals (Ctrl+C)
2. Start again with the commands above
3. Use the NEW link from Terminal 2

---

## That's It! 🎊

The terminal will always show you what you need to copy. Simple!
